# Repository guidelines

- Write production code and documentation for the people who will use and maintain them. Use descriptive names, straightforward control flow, and plain language.
- Implement the agreed design. Leave design assumptions and unplanned design decisions to the developer.
- If you discover a significant design flaw, gap, or inconsistency during implementation, stop work. Explain the issue and its consequences, identify the decision needed, and wait for the developer’s resolution before continuing.
